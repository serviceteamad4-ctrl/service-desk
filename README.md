# Service Desk

ระบบจัดการงานบริการเวอร์ชันที่เป็นข้อมูลของคุณเอง โดยทำงานในเบราว์เซอร์และไม่เชื่อมต่อกับ AppSheet เดิม

## ความสามารถ

- ตารางงานแจ้งบริการพร้อมค้นหาและกรองตามสถานะ/ระดับความเร่งด่วน
- เพิ่มและแก้ไขงาน พร้อมข้อมูลลูกค้า สถานที่ ผู้ติดต่อ นัดหมาย ผู้ดำเนินการ และผลการทำงาน
- เก็บข้อมูลใน `localStorage` ของเบราว์เซอร์เครื่องนี้
- Dashboard รายงานจำนวนงานรายเดือน สถานะ ระดับความเร่งด่วน เวลาเฉลี่ยปิดงาน และอัตราปิดงาน
- ดาวน์โหลดข้อมูลทั้งหมดเป็น CSV เพื่อนำไปเก็บในฐานข้อมูลถาวรภายหลัง

## เปิดใช้งาน

ติดตั้ง dependencies และเปิด development server:

```bash
npm install
npm run dev
```

จากนั้นเปิด URL ที่ Vite แสดงใน terminal โดยปกติคือ `http://127.0.0.1:5173/`

ข้อมูลชุดแรกเป็นข้อมูลตัวอย่างจากรายการที่มองเห็นในหน้าจอเดิม ควรแทนที่ด้วยข้อมูลที่คุณได้รับอนุญาตให้ใช้งานจริง

## โครงสร้าง React

- `src/App.jsx` component หลัก, state, CRUD, ตาราง และรายงาน
- `src/main.jsx` จุดเริ่มต้นของ React application
- `styles.css` visual system และ responsive layout

## ขั้นต่อไปสำหรับใช้งานจริงหลายคน

ย้าย storage จาก `localStorage` ไปยัง PostgreSQL/Supabase หรือฐานข้อมูลบนเซิร์ฟเวอร์ของคุณเอง และเพิ่มระบบล็อกอิน/สิทธิ์ผู้ใช้งานก่อนเผยแพร่ภายนอกเครื่อง
